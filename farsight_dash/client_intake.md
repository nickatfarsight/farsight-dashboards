# Farsight — Weekly Performance Dashboard
## Client Intake

Hi! We're setting up your weekly performance dashboard. To get started, we need a few things from you.

---

## 1. Brand Info
- **Brand name** (as it should appear on the dashboard):
- **Brand color** (hex code, e.g. #4A90D9):
- **Logo file** (PNG, preferably on white or transparent background)
- **Custom font files** (optional — .otf or .ttf, or just tell us the font name)

## 2. Retailers / Channels
- **Which retailers sell your brand?** (e.g. Sephora, Ulta, Target, Nordstrom, Amazon, DTC, etc.)
- **Do you have a DTC / eCommerce channel?** If so, what platform? (Shopify, BigCommerce, etc.)
- **For any retailer, is sales data split into B&M vs Dotcom?** (Y/N, and which retailers)

## 3. Weekly Sales Data *(most important)*
A spreadsheet with weekly sales by SKU and retailer. We need columns like:
- SKU / Item Code
- Year
- Week number (1-52)
- Week ending date
- Retailer name
- This Year sales ($) and units
- Last Year sales ($)
- *(Optional)* B&M vs Dotcom split
- *(Optional)* 4-4-5 fiscal month

> If you already have a weekly sell-through report you send internally, just send it as-is and we'll map the columns.

## 4. SKU Master
A list of all your SKUs with:
- SKU code
- Product name
- Category (e.g. Lips, Eyes, Skincare)
- Suggested Retail Price (SRP)
- Status: Active / Discontinued / New

> This can be a separate file or a tab in your sales database.

## 5. Inventory Data *(optional but great to have)*

**Warehouse / 3PL Inventory**
- Do you have a warehouse/3PL inventory report? (Y/N)
- If yes: file name, columns for SKU, units on hand, cost per unit

**Open Purchase Orders**
- Do you have an open PO report? (Y/N)
- If yes: file name, columns for SKU, PO number, ordered units, expected date

> Inventory data unlocks our Inventory tabs — on-hand tracking, weeks of supply, at-risk SKU alerts.

## 6. Forecast / Demand Plan *(optional)*
- Do you have forecasted sales by retailer and week? (Y/N)
- If yes: file name, and for each retailer what sheet name?
- Are forecasts in dollars or units?

## 7. Store / Door-Level Data *(optional)*
- Do you have weekly sales by individual store location? (Y/N)
- If yes: which retailer? File + sheet name?

## 8. DTC / Shopify Export *(optional)*
- If your eCommerce data comes from Shopify (or similar), export the daily sales CSV
- We'll integrate it alongside your retail data

## 9. Calendar
- **Do you use a 4-4-5 fiscal calendar?** (Yes / No / Not sure)

---

## Dashboard Tabs — Which Do You Want?

**Sell-Through Tabs:**
- [ ] Overview (sales trends, KPI tiles)
- [ ] SKU Performance (ranking, leaderboard)
- [ ] Retailer Detail (per-retailer deep dive)
- [ ] Category Breakdown
- [ ] Forecast vs Actuals *(requires demand plan)*
- [ ] New Launches tracking
- [ ] Store/Door Performance *(requires door-level data)*
- [ ] DTC Performance *(requires Shopify/eComm data)*

**Inventory Tabs:**
- [ ] Inventory Overview (KPIs, WOS, tier distribution)
- [ ] Inventory Detail (SKU table with on-hand, cost, WOS)
- [ ] Inventory Sales (velocity rankings, channel mix, leaderboard)

1. Your **weekly sales data** file (Excel or CSV)

3. Your **logo** + **brand color**
4. *(Optional)* Inventory report, PO file, forecast file, door-level data, Shopify export, font files
